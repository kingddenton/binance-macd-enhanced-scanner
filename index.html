The primary MACD histogram crossover candle is Bar 1. Signals remain eligible through the selected crossover window. All indicators use Binance's latest returned candle, including the currently forming candle. Live values can change before candle close. Enabled MACD timeframes are classified automatically: histogram above zero is bullish, below zero is bearish, exactly zero is neutral. All enabled timeframes must agree. Enabled Supertrend timeframes must all agree with the result direction. Each enabled RSI timeframe has independent bullish minimum/maximum and bearish minimum/maximum ranges. All enabled RSI timeframes must fall inside the relevant range. Mixed bullish/bearish confirmations do not qualify for either side. Every selected DEA timeframe is checked independently: DEA above zero confirms bullish, below zero confirms bearish, exactly zero confirms neither. All selected DEA timeframes must agree. The separate DIF / DEA zero-line filters use the timeframe selected above. DIF and DEA zero-line filters remain independently optional. MACD uses standard 12, 26, 9 settings. Supertrend uses ATR 10, multiplier 3.
